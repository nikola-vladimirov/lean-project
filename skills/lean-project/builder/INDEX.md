# Builder index: Bricks and BricksExtras

Read this file only when a task names Bricks or BricksExtras (a builder page, template, element, query, condition, form, or site audit). Then read only the matching `<skill>/SKILL.md` below, plus its support files it names. Never load the whole folder.

- Source: the 108 Bricks and BricksExtras skills, copied verbatim from `~/.claude/skills-off/bricks/` on 2026-10-16. Frontmatter kept.
- **Generated JSON data** (about 23 MB, element schemas and resolved controls) is NOT in the plugin. It stays at `~/.claude/skills-off/bricks/<skill>/references/`. When a skill names a `references/...json` file, read it there with `Read` offset and limit, and grep it first.
- Runtime reads (site abilities from the connected Bricks MCP servers) override anything here, as `bricks-start-here` says.
- To turn the old standalone skills back on (not needed for this index): `bash ~/.claude/skills-off/parked.sh bricks on`. Do not, or the skills duplicate this copy.
